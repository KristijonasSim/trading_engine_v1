# Local dashboard

The dashboard shows all three engines.

- Research Engine: saved source ideas and market labels.
- Testing Engine: strategy and report count. Testing is not built yet.
- Bot Engine: always locked. It cannot trade.

Run it from the project root:

```bash
python3 -m ui
```

Open <http://127.0.0.1:8000> in your browser.

The dashboard is local only. It does not use a paid API or an exchange key.
